## v3.0.2 固定签名，覆盖安装不再丢数据

版本号：`v3.0.2`（versionCode 302）

### 修复

- 此前每次 CI 构建都用随机生成的 debug 签名，签名一变，系统只能先卸载旧包再装，导致机器人配置、统计与日志全部被清空。
  本版起所有版本（debug 与 release）统一使用仓库内固定密钥 `keystore/smsforwarder-release.jks` 签名，
  以后覆盖安装就是普通升级，本机数据完整保留。
- 两个 APK 签名一致，互相覆盖安装也行（debug ↔ release 可互换）。

### 新增

- **配置备份 / 恢复**：机器人管理页右上角菜单
  - 导出配置到剪贴板：机器人配置 + 统计记录（不含短信正文）打包为 JSON
  - 从剪贴板导入配置：校验后整体替换本机配置，统计记录保留原始时间戳

### 注意

- 从 v3.0 / v3.0.1（随机 debug 签名）升级到本版，需要**卸载一次**再安装；建议先在旧包导出配置，装好新包后导入。
- 本版之后的所有版本都不再需要卸载，直接覆盖安装即可保留数据。
- 功能与 v3.0 一致：三通道监听、关键词条件组（AND/OR）+ 排除词、首页日/周/月统计与关键词 Top5、事件级运行日志。
