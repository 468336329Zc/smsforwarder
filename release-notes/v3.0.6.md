## v3.0.6 统计口径与折线图修正

版本号：`v3.0.6`（versionCode 306）

### 调整

- **总条数改为当前自然周期口径**
  - 日：今天 0 点起当日转发条数
  - 周：本周一 0 点起，当前自然周的转发条数
  - 月：本月 1 号 0 点起，当前自然月的转发条数
  - 环比对比上一等长周期（昨天 / 上一个自然周 / 上一个自然月）。
- **折线图窗口与口径对齐**
  - 日：近 7 天，每天一个点（前 7 天到今天）
  - 周：本月按周一为界切分的各周，每周一个点
  - 月：近 6 个月，每月一个点
  - 每个折点上方标注当期转发条数（0 也显示）。
- 关键词 TOP5 按当前折线图窗口内的命中关键词归类排序。

### 说明

- 规则判定、去重、通知监听、界面其余部分与 v3.0.5 一致
- 固定签名，覆盖安装保留本机数据
- Android 8.0（API 26）及以上
