## v3.1.0 接入离线授权激活

版本号：`v3.1.0`（versionCode 307）

### 新增

- **离线授权激活门**
  - 首次打开进入激活页，未授权不能进入主功能；转发服务在启动时同样校验本机授权，未激活不监听、不转发。
  - 激活全程在本机完成，不需要联网。
- **一机一码**
  - 本机生成 10 字节随机设备码（Crockford Base32 + CRC16 校验，5 组人读格式）。
  - 把设备码发给卖家换取授权码；授权码与本机设备码绑定，换机或重装后原码失效，需用新设备码重新激活。
- **本机验签与校验链**
  - 内置 Ed25519 公钥，按「格式 → 解码 → 版本 → 签名 → 应用标识 → 设备码 → 有效期 → 系统时间」顺序完整校验。
  - 应用标识 `APP_B`（appId `0x0102`）。
- **本地授权记录**
  - 只留存授权码、设备码与期限信息；每次启动重新走完整校验，不只记录一个已激活开关。
  - 设备码与激活记录排除在云备份之外，避免恢复备份后授权串机。
- **激活页文案**
  - 只展示设备码复制、授权码粘贴与激活结果；失败提示只给「原因 + 下一步」，不展示内部编号、算法名与错误码。

### 说明

- 固定签名，覆盖安装保留本机机器人配置、关键词规则、统计与事件记录，激活记录同样保留。
- Android 8.0（API 26）及以上。
