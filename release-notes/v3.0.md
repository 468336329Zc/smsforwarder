## v3.0 重要里程碑

版本号：`v3.0`（versionCode 300）

这一版把三项能力做到可用状态：三通道防漏监听、可组合的关键词规则、转发数据统计。

### 新增

- **首页数据统计**
  - 转发趋势折线图，支持日 / 周 / 月三档切换（近 14 天、近 8 周、近 6 个月），并给出与上一周期的环比
  - 关键词命中 TOP5 排名与次数，用横条对比
  - 统计只记录「时间 + 命中关键词」，本机保留 200 天 / 最多 2 万条，不含短信正文
- **关键词条件组规则（AND / OR）**
  - 组内关键词必须同时出现（AND），多个条件组之间任一满足（OR）
  - 兼容旧行为：可选「任一关键词」模式
  - 新增排除词，命中即不转发，优先于其他条件
  - 旧版「逗号分隔关键词」自动迁移，无需重新配置
- **事件级运行日志**
  - 一条短信从捕获到推送完成合并为一个事件，左侧色条与徽标区分已转发 / 未转发
  - 事件内完整列出通道来源、号码过滤、规则判定原因、去重结果、各机器人推送结果与 HTTP 状态，按结果分色
  - 事件保留 100 条，正文与发件人统一脱敏
- **机器人编辑页规则编辑器**：条件组 / 任一关键词切换、词条 Chip 可逐个删除、可增删条件组、排除词输入、规则实时预览
- **机器人列表摘要**直接显示规则（如「竹云科技 且 验证码 或 4A」），不再是扁平关键词串

### 改进

- 三通道（系统广播 / 通知栏 / 短信库）统一交由转发服务处理，每步都标注来源通道，日志可判断是哪条通道兜住的
- 跨通道去重挪进转发服务，使「去重跳过」成为事件中的一个可见步骤
- 首页布局重新排布：状态卡 → 数据统计卡 → 2×2 快捷操作卡 → 使用提示，统计上线后快捷操作仍然一屏可达
- 权限自查改为状态卡内彩色 chips（短信权限 / 通知监听 / 电池白名单），一眼看出缺哪一项
- 转发成功才计入统计，测试消息不污染数据

### 说明

- Android 8.0（API 26）及以上
- 本版含 `debug`（可直接安装）与 `release-unsigned`（未签名，需自行签名）两个 APK
