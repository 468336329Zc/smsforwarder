## v3.0.4 界面精修

版本号：`v3.0.4`（versionCode 304）

### 改进

- **全部换成矢量图标**：机器人列表头像、发送 / 更多按钮、首页四个快捷入口与 FAB 此前用系统内置位图（`ic_menu_send` 等）放大后发虚，
  改为自绘 vector drawable，40dp 以上尺寸也保持锐利。
- **机器人列表项按原型重排**：44dp 浅紫圆角方块头像 + 深紫矢量图标，名称与规则摘要层次更清楚，右侧开关 / 发送 / 更多三件套对齐。
- **条件组之间加了「或 OR」分隔**：每组之间插一条细线 + 紫色胶囊「或 OR」，不用读说明文字也能一眼看出组间是 OR 关系。
- **条件组卡片重做**：虚线描边 + 淡紫底，组头显示「条件组 N · 组内需同时满足」，删除入口改为右上角红色「删除组」，输入框改成虚线胶囊「再加一个词」，组与组之间留出 20dp 间距，不再拥挤。
- **「新增条件组」改为整行虚线按钮**「+ 新增条件组（或）」，和组卡片同一视觉语言。

### 说明

- 纯 UI 调整，规则判定、统计、日志、通知监听逻辑与 v3.0.3 完全一致
- 固定签名，覆盖安装保留本机数据
- Android 8.0（API 26）及以上
