## v3.0.1 修复安装失败

版本号：`v3.0.1`（versionCode 301）

### 修复

- v3.0 的 `release-unsigned.apk` 未签名，在小米 / Redmi（MIUI、HyperOS）等机型安装时直接报
  「解析软件包时出现问题 (33) packageInfo is null」。本版把 release 构建改用 debug 签名，
  Release 页两个 APK 均可直接安装（无需自行签名）。
- 资产名由 `SMSForwarder-v<版本>-release-unsigned.apk` 改为 `SMSForwarder-v<版本>-release.apk`。

### 说明

- 功能与 v3.0 完全一致：三通道监听、关键词条件组（AND/OR）+ 排除词、首页日/周/月统计与关键词 Top5、事件级运行日志
- 两个 APK 任选其一安装；同一应用只能装一个，覆盖安装会保留本机配置与统计数据
- Android 8.0（API 26）及以上
