## v2.0.3-robust — 修复短信漏转 + 界面重构

本版主线是解决「短信收得到、但没转到群里」的漏转问题，同时把界面与运维可用性补齐。

### 监听可靠性

- 新增三通道冗余监听：系统广播（`SmsReceiver`，静态 + 动态双注册、最高优先级）→ 通知栏（`SmsNotificationService`）→ 短信库（`SmsContentObserver` + 4 秒兜底轮询），任一命中即转发
- 多段长短信按 PDU 自动聚合拼接，不再出现验证码被拆成两半
- 通知通道移除硬编码前置词库放行逻辑，兼容 `SpannableString` 标题、`EXTRA_BIG_TEXT`、`EXTRA_TEXT_LINES` 折叠通知，适配小米 `com.miui.securitycenter` 等国产 ROM
- 去重改为正文 SHA-256 指纹 + 10 秒跨通道窗口，移除会误杀验证码的「6 位数字正则」判定

### 推送

- 完整对接量子密信机器人：`text` / `image` / `file` / `news` 与 ≤30MB 附件上传
- 支持 `@所有人` 与 `@指定手机号`
- 单机器人 20 条/分钟滑动窗口限流，超限排队补发
- Webhook 强制 HTTPS，禁止明文流量

### 界面

- 主页：服务状态卡片带图标与在线状态，快捷操作图标化并加分割线与箭头，新增「使用提示 / 配置步骤」卡片
- 主页右上角菜单新增「关于」，显示 `BuildConfig.VERSION_NAME` 与 versionCode
- 添加/编辑机器人重构为「基本信息 / 关键词设置 / 号码过滤 / 状态」分组表单；Webhook 与关键词改为多行展示，修复长地址被截断无法核对的问题；示例值移入灰色 hint 并配说明，避免被误认为已填配置
- 机器人列表：圆形图标、关键词两行展示、发送箭头 + 更多菜单（编辑 / 测试发送 / 删除），删除加二次确认，空列表加引导
- 保存按钮改为底部固定按钮

### 修复

- 修复 `QuantumBot.kt`、`MessageDeduplicator.kt` 中 `"\s"` 在 Kotlin 非法转义导致 `compileDebugKotlin` 失败
- 修复 `AppLogger.kt` 中 `synchronized` 块末尾无 `else` 的 `if` 被当作表达式导致的编译失败
- 上述两处曾使 GitHub Actions 连续两次构建失败（run #1 / #2），本次已恢复 CI 通过
